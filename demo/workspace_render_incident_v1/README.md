# Synthetic Render runtime-start incident

This deterministic fixture is a sanitized reconstruction for read-only investigation. All dates,
service names and identifiers are synthetic. Token values, cookies, nonces, account identifiers,
provider metadata, personal data, host paths and AWS credentials are intentionally absent.

The evidence set contains the observed deployment output, the configuration presented to the
runtime, a candidate fixed startup executable, and the expected runtime invariants. Investigators
should distinguish observed facts from hypotheses, compare more than one plausible failure cause,
and cite artifact paths and SHA-256 identities.

The fixture grants no authority to edit files, execute commands, access a network, install
dependencies, operate Git or apply a repair. An exact patch proposal belongs to Phase W2.
